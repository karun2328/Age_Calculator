# 🎂 Age Calculator

A simple and interactive web application that calculates your exact age based on your date of birth. Built using **HTML, CSS, and JavaScript**, this app provides a quick way to find out your age in years, months, and days.

---

## 🚀 Features

- 📅 Input your date of birth.
- 🔄 Instantly calculates your:
    - Years
    - Months
    - Days
- 🖥️ Responsive design (works on mobile and desktop).

---

## 🛠️ Technologies Used

- **HTML** – for page structure.
- **CSS** – for styling and layout.
- **JavaScript** – for age calculation logic.
